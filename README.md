# Lineage 2 Valheim Buffs

Current proof of concept: a per-character Fighter selection, a character-wide Lineage level from 1 to 20 with post-level-20 profession progression, class-based native Valheim skill levels, a bottom-center progression bar, Wind Walk, level-gated Might and Shield buffs, a 12-slot-per-row skill hotbar with a separate active-buff display, a Lineage-style menu launcher, and a custom inventory view backed by the player's real Valheim inventory.

The in-game vital display uses one painted panel below the buff strip for live health, stamina, and eitr bars. Three food icons appear in a horizontal row beneath those bars, labeled with the active slot count and remaining minutes. Its left grip moves the panel while a UI window is open or Alt releases the cursor, and the position is saved per character. Valheim's separate health, stamina, eitr, and food UI roots and leftover food icons are hidden while the mod is active.

## Current test loop

1. Build this project with `dotnet build`.
2. The build copies `Lineage2Valheim.dll` into the configured r2modman profile's `BepInEx/plugins/Lineage2Valheim` folder.
3. Launch the `My-Mod` profile and enter a world.
4. Earn Lineage XP by killing monsters, felling trees, depleting ore nodes, and placing paid building pieces. XP is saved with the character. The wide XP bar is centered at the bottom edge of the screen, independently positioned from the skill and buff bars; requirements rise quadratically to the level 20 cap. Open **Skills** with **F8**. Might (+10% physical damage) requires level 5 and Shield (+10% armor) requires level 10. Drag learned buffs from **Active Skills → Buffs** onto the skill hotbar. Wind Walk (+20% movement speed for 5 minutes) is available immediately. Use **1–0** for the first ten slots or click a slot while holding **Alt**. Learned state is saved with the character.

## Fighter class progression

Each character without a saved class sees a Fighter confirmation once after its player data loads. The choice is saved in character custom data and mirrored to that player's ZDO so other peers can identify the class. At Lineage level 20, choose Knight, Warrior, or Rogue; Rogue also chooses Assassin or Archer. Profession XP starts after level 20 and uses the same activity rewards. XP earned after Lineage reaches 20 is held on the profession track, including before the specialization choice is made.

After Fighter is selected, normal `RaiseSkill` XP is suppressed for all native Valheim skills. Jump, Run, Swim, and Dodge follow the shared Lineage curve. Knight maps Swords and Blocking; Warrior maps Axes, Clubs, and Swords; Rogue Assassin maps Knives and Sneak; Rogue Archer maps Bows and Crossbows. Other native skills remain visible and frozen at their saved levels. On Fighter selection, the mod snapshots all 24 skill levels once. A mapped skill uses the greater of its saved baseline and its class target, so an existing character never loses skill levels. The proposed movement targets (5/10/20/30/40) and profession targets (5/15/30/45/60) are draft values in `CharacterClassSystem.cs` and can be adjusted there.

Knight emphasizes Blocking and defense, Warrior receives the broader melee weapon mapping with higher stamina commitment and less defense, and Rogue paths focus on either stealth/knives or ranged weapons. This first version changes native skill progression and presents these roles; it does not add permanent hazard immunity or make equipment, food, meads, or preparation unnecessary. Class, profession, and Rogue path are mirrored to the owning player's ZDO for peer identification. Native skill levels remain in the owning character save and are applied locally; there is no separate per-skill network broadcast, so other peers should use the synchronized class identity rather than depend on a mirrored remote skill level. Validate ZDO replication and existing-character migration in game before relying on class data for server-side mechanics.
5. Check `BepInEx/LogOutput.log` for plugin load and application messages.

Hostile, untamed creatures have 4× their normal maximum health by default to make early fights last longer. Change `Balance/HostileMobHealthMultiplier` in the generated BepInEx config; set it to `1` to disable the adjustment. This does not change their damage. Kill XP is calculated from the creature's unmodified health, so the health setting does not inflate its reward.

## Menu UI

Four buttons appear in the bottom-right while in a world: Inventory, Skills, Crafting, and Character Status. Inventory and Crafting open the same draggable Unity Canvas. A crafting panel sits to the right of the inventory scrollbar. It lists Valheim's currently available recipes, lets you scroll and select one, shows required materials and station level, and uses Valheim's crafting method when you press Craft. The first implementation crafts one batch immediately; upgrade and repair tabs are not yet connected. The inventory uses the painted hotbar slot sprites for its grid, equipment slots, and trash target. Its middle panel is narrower, with the scrollbar closer to the grid and crafting divider. The hotbar frame art is also used for the window border, title rule, section dividers, and small interior trims. It has square equipment slots, a temporary character illustration, a 6-column by 18-row scrolling item grid, hover tooltips, and carry weight. The illustration now shows an unarmored variant when no chest armor is equipped and a dressed variant when chest armor is equipped; it remains a static placeholder and does not reproduce each individual armor set. The live character preview camera is disabled while investigating its effect on scene brightness. Tooltips follow the cursor each frame over items in the grid or equipment slots. The grid cells are 25% smaller than the previous version. The mod expands the player's underlying inventory to 108 slots; existing items outside the new six-column width are moved to free positions. Skills has Active, Passive, and Learn tabs. Character Status uses the same dark iron and gold style and shows live player vitals, weapon physical damage, body armor, and a relative run-speed rating. Armor sits on the left, jewelry on the right, and weapon, offhand, and ammunition below the character. Boots, earrings, and rings remain visual placeholders because Valheim has no separate item slots for them yet. Equipped items are shown only in the equipment slots; they remain in Valheim's underlying inventory data. Double-click an inventory item to equip it or use it if it is consumable. Double-click equipped gear to unequip it. Drag gear onto a compatible equipment slot to equip it, or drag equipped gear back into the inventory area to unequip it. Drag an item outside the window to drop its full stack. Opening the game's normal player inventory opens this custom window; container inventories still use Valheim's normal UI. Opening it releases the cursor and freezes local movement and combat input while leaving the game camera active for normal scene lighting.

Press **Tab** to open or close Inventory, **F8** for Skills, **F9** for Crafting, and **F10** for Character Status. Press the **Backquote** key to toggle mod debug mode; while it is on, hold **Alt** and click an active buff to remove it. The XP bar also shows **−** and **+** controls in debug mode to decrease or increase Lineage level by one. **Escape** closes the open window. F8–F10 can be changed in the plugin's BepInEx configuration under `UI`. Opening a window releases the mouse and blocks player input until it closes. The Skills list shows a scrollbar only when its contents exceed the visible area. The 108-slot inventory grid reuses eight visible rows, and the recipe list refreshes once per second to reduce UI work while the window is open.

The mod expands the player inventory before Valheim validates saved item positions on spawn, preventing rows beyond Valheim's temporary inventory height from being dropped. Closing the inventory hides its Canvas for reuse instead of destroying and rebuilding its textures. Empty equipment overlays start hidden so slot art remains visible. Characters saved with items in the extra rows need this mod enabled when loading; vanilla Valheim cannot fit those positions.

The active-skill framework supports level unlocks, stamina and eitr costs, cooldowns, effect windows, hotbar assignment, and optional validated character animator triggers. **Power Strike** is the first action skill: learn it at level 1, then use it from the skill window or hotbar to automatically perform one normal weapon attack, aiming at a hostile creature under the crosshair when one is available. If it hits a hostile creature within 3 seconds, that hit deals 50% bonus physical damage. It costs 5 stamina and has a 12-second cooldown. The attack uses Valheim's normal weapon swing animation; custom animator triggers can be assigned as other skills are added. The hotbar displays the active window or remaining cooldown on the Power Strike slot.

The cached Canvas is released when a world unloads, and a new one is built for the next world. This prevents stale Unity images from turning item and crafting icons into white squares after a world transition. Empty icon images start hidden until a real sprite is assigned.

## Character Status

Press **F10** or use the bottom-right character button to open the status sheet. It follows the Skills window styling without a character portrait. Health, stamina, eitr, equipped weapon physical damage, current body armor, and a run-speed rating update from the local player. The run-speed rating uses 100 as the unmodified baseline; active status effects may alter movement further. Hover each stat for its definition.

Attack speed shows a dash until weapon animation timing is measured reliably. Critical chance and passive evasion show 0% because this mod has not added those combat mechanics yet. Their entries distinguish random critical hits from Valheim's combo finishers and passive evasion from dodge rolls. These displayed numbers do not currently modify combat.

## Skill and buff hotbars

Valheim's numbered item hotbar and the mod's earlier eight-slot buff bar are replaced by a 12-slot skill and consumable bar. Drag a learned skill icon from **Active Skills** onto a slot, or drag a consumable from the inventory onto a slot. The first ten slots use **1–0**; every visible slot can be clicked. Hold **Alt** during play to release the cursor for clicking or moving the bars. Drag the narrow grip on the left edge to reposition a bar. The button at the right cycles one, two, and three rows. Skill and consumable assignments, row count, and both bar positions are saved in the character's custom data. Dragging an assigned skill onto another slot swaps the two assignments. Right-click a slot or drag its skill outside the bar to clear it.

A second display bar appears only while one of this mod's Valheim status effects is active. It shows active buff icons, and a countdown appears on an icon only during its final 60 seconds. Hovering shows the buff name, remaining time, and effect description. Its icons do not activate skills. By default it sits above the skill bar. The mod's buff icons are hidden from Valheim's top-right status list so they appear only in this strip. Its left grip is movable in the same way. The built-in numbered item hotbar is hidden, and its item-use hotkeys are suppressed while this mod is loaded.

The bars now use the painted hotbar sprite set in `ui-preview/assets/hotbar/`. The slot art is embedded in the plugin, the outer frame is drawn in nine slices so its corners do not stretch as rows are added, and the same frame is reused around the active-buff strip. The movement grips and row control use their matching sprites. Art is loaded once when the plugin starts. Extra skill rows expand upward while the numbered shortcut row stays in place; the row count appears inside the control.

The game and profile paths are currently configured in `Lineage2Valheim.csproj`. Override them at build time with `/p:GameDir="..."` and `/p:ModProfileDir="..."` if needed.

The first iteration uses a temporary hotkey and no external library. The icon is embedded in the plugin DLL, so it does not need a separate installation step. Additional buffs can be added as slots in the same horizontal bar using the [skill template](SKILL_TEMPLATE.md).

Buffs cast over 2.5 seconds by default. Their gameplay effects begin only after the cast completes. The temporary VFX use tapered procedural ribbon meshes, a ground-aligned runic circle, hand sparks, arcane motes, brief electrical arcs, a controlled release, and a short fade. All casting objects are destroyed independently of buff duration; no visible aura remains while a buff is active. Casting can be interrupted by movement, damage, dodge, attack, death, or teleport. Nearby clients receive a short cast event rather than per-frame particle state. Existing Valheim staff-summon animation triggers are used when available, with the built-in cheer emote as a fallback.

Buff casting options are in the BepInEx config under **Buff Casting**: duration, VFX toggle and intensity, ribbon count, particle density, magic circle, temporary cast light, and residual fade. Disabling VFX does not disable casts or buff effects.
